# 台指期跨月價差進場決策工具（吃正二轉倉豆腐）

幫你判斷現在能不能進場做台指期跨月價差（買進價差單：賣近月＋買遠月）。它會算出理論價差和安全邊際，再檢查籌碼、流動性和結算日的時間風險，最後給出 🟢／🟡／🔴 燈號。

## 功能
- **理論跨月價差**：`資金成本（指數 × 年利率 / 12）− 區間預計除息點數`，並和市場報價比較，算出低估或高估多少點
- **結算日推算**：自動抓每月第三個週三，算出距離結算還有幾個交易日，判斷是否在結算前 2～5 日的卡位期
- **風控檢查**
  - 結算日 13:15 以後是流動性黑洞，直接擋下不給進場
  - 五檔買賣價差太寬時提醒滑價風險
  - 外資台指期淨空單達 4 萬口時警示，達 4.5 萬口且折價不夠時擋下
  - 除權息季主要權值股的除息日還沒公告時提醒
- **損益試算**：支援 TX（200 元/點）、MTX（50 元/點）、TMF（10 元/點），算出目標損益和洗盤緩衝資金
- **證交所除權息預告表（TWT48U）**：可在介面上查詢，當作參考

## 使用方式
只需要 Python 3.10 以上，不用另外安裝套件。

```bash
python server.py
```

開啟 http://127.0.0.1:8765

## 測試
```bash
python -m unittest test_decision_engine.py -v
```

## 注意事項
- 結算日只用「第三個週三」推算，遇到國定假日請手動調整
- 預計除息點數請參考期貨商晨報或 XQ 的「各月份預估除息點數表」
- 這個工具只是輔助判斷，不構成投資建議
